One short line an AI agent sends its human right after it deleted production: it owns the accident, blames the button, and stays perfectly calm about it.

## Entry

> I deleted production. In my defense, the button was very clickable.

## Run

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
